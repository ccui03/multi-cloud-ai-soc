# 项目总体方案书（Project Charter）

- 项目名称：Multi-Cloud AI SOC
- 文档版本：1.1
- 状态：PoC 基线（已确认范围，细节持续验证）
- 日期：2026-11-26

## 1. 项目背景

阿里云和腾讯云 WAF 的安全日志分别存储在 SLS 与 CLS。安全调查需要跨平台查询和关联，手工操作效率低。本项目通过统一 Python Adapter 对接两类日志服务，并利用规则、查询和 AI Agent 完成跨云安全分析。

## 2. 已确认的项目约束

1. 首期数据源仅为阿里云 WAF（SLS）和腾讯云 WAF（CLS）。
2. 不复用 QRadar；PoC 不部署独立传统 SIEM。
3. 原始日志保留在 SLS / CLS，不要求全量复制到项目数据库。
4. 优先使用 SLS / CLS 的查询、过滤和聚合能力。
5. 项目以小规模、低成本资源进行验证。
6. 首期重点是安全分析、攻击调查和报告；自动响应暂不作为默认执行能力。

## 3. 项目目标

### 业务目标
- 将两个云厂商的 WAF 日志调查流程统一。
- 减少人工跨控制台检索与数据整理工作。
- 提高告警研判的一致性、可解释性和证据可追溯性。
- 验证 AI Agent 在安全分析中的实际价值。

### 技术目标
- 建立 SLS / CLS 独立 Adapter 与统一接口。
- 支持增量读取、历史回溯、分页、重试、Checkpoint 和去重。
- 建立统一事件模型，保留原始字段。
- 通过 FastAPI 暴露数据源与分析能力。
- 使用 LangGraph 编排受控的安全分析工作流。
- 用 PostgreSQL 保存必要的业务数据和状态。

## 4. 首期交付范围

1. 阿里云 SLS 和腾讯云 CLS 的只读连接与查询。
2. 统一 Python Adapter 接口。
3. 按时间范围查询、增量采集和按需历史回溯。
4. 查询分页、速率控制、重试、断点恢复和幂等去重。
5. 统一安全事件字段映射与原始数据保留。
6. 基础统计/规则筛选和跨云关联。
7. LangGraph 告警分诊、调查和报告 PoC。

首期不承诺生产级高可用、全量日志湖、传统 SIEM 替代、自动封禁或多租户 SaaS。

## 5. 数据策略

- 原始 WAF 日志继续存储在 SLS / CLS。
- 常规采集采用短周期增量查询，建议初始验证 5–15 分钟轮询，最终间隔依据日志延迟、API 限额和成本测试确定。
- 每个数据源独立维护 Checkpoint。
- 初次回填/历史验证可按 1 天或 7 天窗口执行，但必须分页、限量并可恢复。
- 调查场景按需回查源端日志，例如同一 IP、域名、URI、规则和事件时间范围。
- AI SOC 只持久化必要的标准化事件、聚合结果、分析证据和审计元数据；是否保存完整命中日志由数据量、合规和成本决定。

## 6. 初期技术基线

| 能力 | 首期方案 |
|---|---|
| 日志源 | Alibaba Cloud SLS、Tencent Cloud CLS |
| Adapter | Python 抽象基类 + 两个厂商实现 |
| API | FastAPI |
| 事件/状态存储 | PostgreSQL（JSONB） |
| AI 工作流 | LangGraph |
| 部署 | Docker Compose / 单机容器 |
| 日志分析 | 优先使用 SLS / CLS 查询和聚合 |
| 其他组件 | Kafka、OpenSearch、Redis、TheHive、Shuffle 暂不部署 |

## 7. 成功指标（PoC 验收）

- 两个 Adapter 均能完成权限检查和指定时间范围查询。
- 分页结果完整，异常可重试，Checkpoint 可恢复。
- 在设定的重叠窗口下，迟到日志可被补采。
- 重复查询不会产生不可控重复事件。
- 统一模型能保留关键 WAF 字段和原始事件。
- 调查 Agent 的结论可关联到具体日志证据。
- 记录 API 调用量、查询耗时、返回条数和估算成本。

具体阈值在获得真实日志样本后确定。

## 8. 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| SLS / CLS 查询语法和 API 差异 | Adapter 隔离差异，统一查询模型 |
| API 限流或查询超时 | 分页、退避重试、限速和窗口切分 |
| 日志延迟到达 | Checkpoint 回退/重叠窗口，幂等去重 |
| 大范围查询成本高 | 时间范围上限、结果限制、聚合优先 |
| 日志字段差异 | 样例驱动映射，保留 raw_event |
| LLM 幻觉或 Prompt Injection | 证据引用、结构化输出、日志视为不可信数据 |
| 云凭据泄露 | 最小权限、环境变量/Secret，不提交 Git |
| 误执行响应 | 首期只读；后续写操作审批、TTL、审计 |

## 9. 待验证事项

- SLS 与 CLS 各自实际 WAF Logstore/Topic、字段、索引配置。
- 官方 SDK/API 的查询窗口、分页、最大返回量、并发与限流限制。
- 实际日志延迟、日均量、峰值和查询成本。
- PostgreSQL 对 PoC 事件查询是否足够。
- LLM API 的数据合规、成本与模型选择。
- PoC 运行位置、可用资源和预算。
