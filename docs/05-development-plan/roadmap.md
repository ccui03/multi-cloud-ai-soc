# 开发路线图（Roadmap）

> 周期为初步估算，需根据数据源、可投入时间和环境调整。

| 阶段 | 目标 | 主要任务 | 交付物 |
|---|---|---|---|
| Phase 0 | 项目基线 | 明确首个云 WAF、数据量、环境和验收标准 | 已评审需求与架构 |
| Phase 1 | 数据接入 PoC | 获取脱敏样本、开发 Adapter、解析、标准化、检索 | 可运行采集链路 |
| Phase 2 | 检测与事件 | 规则、聚合、去重、事件 API | 告警/事件闭环 |
| Phase 3 | AI 调查 | LangGraph、工具接口、证据引用、报告 | 调查 Agent PoC |
| Phase 4 | 情报与审批 | 情报查询、审批工作流、审计 | 安全响应 PoC |
| Phase 5 | 平台化 | Web UI、部署、监控、测试和文档 | 可演示的端到端系统 |

## 建议的第一批 GitHub Issues

- [ ] 确认首个 PoC 云 WAF 数据源
- [ ] 收集并脱敏 100–500 条真实日志样本
- [ ] 整理字段字典和日志获取方式
- [ ] 明确 PoC 部署环境和预算
- [ ] 定义统一事件模型 v0.1
- [ ] 编写日志 Adapter 最小原型
- [ ] 建立本地开发环境和自动化测试

## 里程碑验收

Phase 1 的最低验收标准：能够稳定获取指定时间范围内的日志；重复拉取不会造成不可控重复；解析失败可定位；标准化事件可按时间、来源 IP、域名和动作检索。
